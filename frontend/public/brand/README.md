# Wayfinder assets

The approved mark is the W-shaped route with two open checkpoints. The wordmark
is **Wayfinder** in Geist 600. The primary color is Muted Violet `#6550B9`.

The site uses four image files:

- `wayfinder-mark-violet.svg`: transparent W mark used in the header.
- `wayfinder-lockup-violet.svg`: violet mark with the ink wordmark. It embeds
  Geist 600 so the lettering works without a separately installed font.
- `../favicon.svg`: white W on a violet tile, simplified for small sizes.
- `../favicon.ico`: 16, 32, and 48 px fallback icons in one file.

`Geist-OFL.txt` covers the embedded font. Keep at least half the mark's height
clear around the composition. Do not stretch, rotate, or add effects.

The favicon omits the open checkpoint rings so the W remains readable at 16 px.
Create other colors, PNG exports, or home-screen icons only when needed.
