# users
Goal: explain who uses or operates the product and what each role needs to achieve.
Use: authentication and permission code, user workflows, product docs and operator docs.
Prepare: supported roles, their goals, access boundaries and main interactions. Separate end users, administrators, operators and external clients only when supported. Connect each role to relevant scenarios.
Select: actor objects, capability claims and scenario references.
Visual: context relationships from actors to capabilities when supported; avoid invented persona portraits.
Missing evidence: state which roles, permissions or user needs are unknown. Do not invent demographics, customers or usage statistics.
