# overview
Goal: explain what the product is, why it exists and where its boundary lies.
Use: README, product docs, key entry points and supported scenarios.
Prepare: a concise product definition; the problem and supported outcomes; scope and documented non-goals; how users receive value; current implementation status. Distinguish stated goals from inferred intent.
Select: purpose/outcome claims, core capabilities, actors and product boundary objects.
Visual: a context diagram showing users, product and real external dependencies when the shared model supports these boundaries.
Missing evidence: do not invent a market, customer, revenue model or roadmap. Name missing business context.
